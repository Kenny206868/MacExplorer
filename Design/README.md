# Interactive design

Open `index.html` directly in a modern browser. No build step, server, npm package, network-loaded font, or API key is required. All CSS, vector icons, sample-data state, and interaction code are in the HTML file.

Try tabs, breadcrumb editing, Home/This Mac/Gallery, sorting, grid/details, multiselection, creation/rename, cut/copy/paste, drag within the demo, Trash/restore, undo/redo, context menus, tags/properties, settings, and light/dark themes. The interaction guide in the header lists shortcuts. Browser-reserved shortcuts may remain controlled by the browser.

Changes affect fictional sample files stored in this page's localStorage only. Reset Demo restores the sample filesystem. macOS operations such as sharing, server connection, and actual document Quick Look are explicitly identified as previews here; their real implementation is in the SwiftUI app.

The initial hosted preview is temporary. GitHub Pages publishing is included for durable hosting after the repository owner enables Pages with the GitHub Actions source. Source/design ZIP workflows preserve standalone downloads independently of the hosting provider.
