# Native commands, comparison and window integration

The native **Commands** palette (Command–Shift–P / Control–Shift–P) adds contextual availability reasons, visible shortcuts, bounded Unicode/fuzzy search, keyboard navigation and explicit execution. Actions capture their originating pane, tab, selection and clipboard; execution follows the actual sheet-dismissal callback rather than an animation delay. Touch file actions use the same mechanism.

Dual panes gain **Compare Pane Folders…**. Metadata matches are separated from byte-verified main file data. The comparison is current-level and read-only: mark/filter results and select the corresponding paths in a pane, then use the normal copy/move workflow. Links, special files, subfolder contents, online-only data and resource-limit exclusions are not silently called identical. Changes to files, pane roots or tabs stop stale report actions.

The workspace now uses an actual macOS customizable toolbar, standard window controls and represented-folder integration, with independent pane tab/location/search strips and a shared information status bar. Complete titled-window captures supplement the existing production-content captures. The original native design, fitted Details columns, in-place rename, gestures, modifier-free selection, native file promises, undo/recovery, archive browsing and Settings remain in place.

The mandatory native contract contains **98 captures per platform**: 78 earlier content states, eight command states, six comparison states and six complete native windows. Every published alpha carries matching source, native ZIP/DMG, PNG galleries, toolchain evidence and checksums from the exact successful commit. The command palette supports both tested toolchains through focused SwiftUI subviews rather than relaxed checks.

Core and native tests do not replace a complete physical-device, provider or assistive-technology audit. Alphas are ad-hoc signed, not Apple notarized, and do not modify the stable signed Sparkle feed. Apple and production updater credentials require owner configuration. Remaining parity includes editable virtual archives, full crash journaling, advanced provider compatibility and representative hardware/accessibility evaluation.
