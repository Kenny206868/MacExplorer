# Direct paths and instant terminal commands

The active Explorer or Commander pane has a single-click full-path editor, not an opaque breadcrumb-only bar. Command-L, Control-L, F4 and Command-Shift-G activate it. Native text selection selects the complete Unicode path. Tab completes a bounded folder suggestion; arrows choose a suggestion; Return navigates; Command-Return opens a new tab; Escape leaves the current location unchanged. Paths may be absolute, relative to the original pane location, home-relative, quoted, or local file URLs. A file path reveals the file in its containing folder rather than running it. Server URLs are handed to the existing system connection route only after explicit submission. Password-bearing URLs and control characters are rejected.

Completion and submitted-path validation have dedicated bounded filesystem worker lanes. They do not enumerate on MainActor or queue behind a long checksum job. Suggestions are shallow, size/time-budgeted, capped at 12, and cached briefly. A full path can always be submitted when suggestions are truncated. Generation checks discard stale results after typing, cancellation or navigation. Blocked kernel/network operations are not claimed forcibly interruptible; the UI stops awaiting canceled work.

Command-Option-Return opens the active pane's committed directory in Apple Terminal. Command-Shift-Option-Return opens both pane locations, deduplicating identical directories. These shortcuts reserve Control-Option for VoiceOver, ignore key-repeat and do not launch from behind file dialogs. Archive locations target the physical archive's containing folder; discovery, tag and Trash namespaces are not shell directories. The request captures URLs before asynchronous validation and uses Launch Services URL opening, never shell text or interpolated AppleScript. Terminal launch/window preferences and filesystem access remain controlled by macOS and Terminal.

Native tests use real NSEvents and injected launch receivers so CI never opens users' shells. They validate active/both directory routing, metacharacter-containing paths, modal guards, deduplication, directory validation and stale navigation. This verifies command delivery and folder URLs, not an unobserved physical Terminal session or device-specific gesture behavior.
