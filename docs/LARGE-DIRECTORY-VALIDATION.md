# Large-directory rendering and input validation

The Details row no longer observes every publication of the entire tab and workspace. Its selected/focused/touch state is passed as values through an equatable boundary. Unchanged rows retain their view/thumbnail/editor state; selection changes update the affected rows. Column layout, appearance, input density, hover, filename-edit sessions and real file metadata still invalidate the views that need them.

`LargeDirectoryScrollTests` creates 2,000 ordinary files in a disposable directory, uses the production asynchronous BrowserTab listing and SwiftUI Details surface in a real NSWindow, and scrolls its actual NSScrollView. It asserts bounded live row anchors, localized row-body evaluations, stable selection during scrolling, and no extra filesystem listing or presentation-sort starts during input. Two hundred native NSEvent key-downs exercise the production keyboard router.

The report records median, p95 and maximum timings for selection/layout, 16 cold 180-point scroll jumps, 120 six-point continuous scroll deltas through an already visited region, and key dispatch. Explicit layout/display/CATransaction flushing is included. These phases must not be confused with display refresh rate: they measure CPU-side work, not GPU completion, physical input delivery or input-to-photon latency.

Both native visual jobs produce the debug report beside their 112-view galleries. The macOS 26 job additionally builds the same test in optimized release configuration with `MACEXPLORER_PERFORMANCE_DIAGNOSTICS`, enabling aggregate render counters that are disabled in ordinary distribution builds. Its report and test log live under `optimized-performance/` inside the native review artifact and therefore accompany exact-commit alpha galleries. The job fails if the release test did not run, the fixture or sample counts are missing, rendering counters are disabled or row realization/selection fan-out exceeds the structural budgets.

Shared CI timings are diagnostic evidence, not an FPS advertisement or universal hardware guarantee. The structural assertions are hard gates; timing samples guide profiling on representative 60/120 Hz Macs, mounted network folders and File Providers. Existing snapshot, selection, rename, column, clipboard and drag tests continue to exercise the same production row. Filesystem and archive operation durability contracts are unchanged.
