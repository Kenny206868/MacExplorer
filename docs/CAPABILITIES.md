# Capability matrix and release boundaries

This matrix describes source behavior, not an assertion that an unfinished CI run passed. Every native distribution and screenshot gallery carries its exact commit. Browser design interactions use fictional data; the native app performs real filesystem operations.

| Area | Implemented user workflow | Remaining boundary |
|---|---|---|
| Native design | Shared light/dark tokens, explicit Explorer chrome, resizable sidebar/auxiliary panes, populated Home cards, native artwork, readable metadata and all five Settings pages | Not Microsoft artwork or private shell code; no replacement of other applications' open/save panels |
| Dual browsing | Independent visible tab strips, location editors, ancestor menus, expandable searches, histories, selections and layouts; active-pane indicators; side-by-side/stacked resizing; narrow fallback | Automatic bidirectional folder synchronization is not implemented; wide-only auxiliary panels retain user preferences |
| Cross-pane transfer | Explicit source/destination direction, Copy and confirmed Move, captured source/destination identities, shared collision and undo engine | Not a whole-filesystem atomic transaction |
| Tabs/windows | Live-tab reorder/transfer between panes and windows, duplicate/reopen/close others/right, source-retaining acknowledged detachment, durable open/closed-window sessions | Desktop drag-out requests detachment only for an unambiguous outside mouse release; conservative fallback is explicit Move to New Window. Hardware/WindowServer delivery needs evaluation |
| File views/columns | Details, list, content, tiles, icon sizes and Gallery; fitted default columns; sort, resize, reorder, show/hide, autosizing and persistence | No arbitrary Windows shell-extension columns; explicit oversized columns may require horizontal scrolling |
| Selection | Command/Control toggle, Shift range, separate focus/anchor, checkboxes, type-ahead, grid/Details marquee with edge scrolling; collapsed groups excluded from actionable keyboard selection | Broader provider and assistive-technology scenarios still require interactive evaluation |
| Keyboard | Native Command and Explorer Control shortcuts, F-keys, page/boundary navigation, type selection, pane/tab switching, focus cycling, action/help panels, shared modal guards | Text editors/dialogs retain their keys; Control–Option is reserved for VoiceOver. Physical function keys follow the keyboard's Fn configuration |
| Touch/gestures | Larger common controls/file rows, modifier-free Select, explicit Open/actions, stationary long press, trackpad history/pinch, Gallery zoom, pressure/smart zoom Quick Look, mouse navigation buttons | Device/driver and OS gesture assignments determine actual delivery. This is a macOS app, not an iPad runtime or a universal touchscreen driver |
| Drag/drop | Native multi-file URLs and promises, owning-pane selection, incoming private staging, folder/file-area destinations, Shift-to-move and spring-loaded navigation; text rename cannot start a file drag | Full live cross-process behavior is not verified for every provider/receiver; source deletion never follows only a reported drag mask |
| Clipboard | Native file URL pasteboard, cut dimming, generation-scoped reservation and completed-source reconciliation | External apps do not share MacExplorer's private cut marker |
| Copy/move/merge | Coordinated staging, Keep Both/Skip/Replace/Merge, independent leaf conflicts, replacement backups, retained source containers and incremental recovery records | Completed merge work survives cancellation; cross-volume moves are not a complete crash transaction |
| Progress | Queue, measured native copy/logical bytes, clone accounting, throughput history, estimates, cooperative pause/cancel and detailed errors | Not physical disk-controller I/O; blocking calls and cloud/network providers may delay progress |
| Rename | In-place single-item editing in native file views, extension-aware Unicode selection, Escape cancellation, validation and guarded queue commit; multi-item preview, templates, cycles/swaps and undo | Representative-volume normalization/case behavior needs evaluation; process races remain guarded by the filesystem layer rather than assumed impossible |
| Undo/recovery | Completed-step receipts, cycle-safe inverse rename, reversible merge containers, change detection and history | Not a complete write-ahead crash journal; metadata edits and permanent deletion are not undoable |
| Trash/delete | Native Trash, tracked restore locations, confirmed permanent deletion | Original paths for unrelated apps' Trash entries are not inferred; no global Empty Trash or secure-erase guarantee |
| Archives | ZIP creation, real archive-header browser, navigation/filter/selection, password-aware selective/all extraction, expansion limits, quarantine propagation and unsafe-entry rejection | No in-place archive editing or main-window archive virtual filesystem; supported encryption follows libarchive |
| Properties/search | Dates, sizes, permissions/ownership, locks, tags, SHA-256; recursive metadata/name search, Spotlight content/tag/whole-Mac queries, saved searches | No privileged ACL editor, NTFS alternate streams, full Windows AQS, or immunity to indexing/permission limits |
| Preview/Gallery | Bounded real image/PDF rasterization, native icons, filmstrip, zoom and preview-only rotation, Quick Look fallback | No Photos database integration; unavailable cloud content needs downloading |
| macOS integration | Open With, sharing/AirDrop, Finder tags, volume capacity/eject, Terminal, Services, login items, opt-in reversible folder association | Private Finder desktop/Dock services and OS protections remain in place |
| Network/cloud | Bonjour SMB discovery, system server authentication, mounted shares, iCloud download/eviction and File Provider roots | No invented provider-specific synchronization state or Active Directory/workgroup parity |
| Validation | Core/disposable filesystem tests, real SwiftUI PNGs, reference geometry/palette, independent pane state, native text/event routing, all Settings pages and active inline editors | Sampled images and tests do not establish complete UX parity, physical hardware interoperability or an end-to-end VoiceOver audit |
| Distribution | Universal Apple Silicon/Intel ZIP and DMG, exact-commit alphas with source/design/native galleries/checksums; signed production update/notarization pipeline | Current alphas are ad-hoc signed, not Apple notarized; production Apple/Sparkle credentials require owner configuration |

## Evidence

The source's mandatory visual contract is **78 captures per platform** on macOS 15 Intel and macOS 26 Apple Silicon. The latest reported successful older milestone may have a smaller contract; inspect the exact release's manifest rather than applying a newer count to an older binary.

Full Windows/Finder equivalence is not claimed. Windows COM extensions, NTFS/BitLocker features and private Finder services are not interchangeable with public macOS APIs. Remaining development includes editable virtual archives, stronger crash transaction journaling, advanced provider/search compatibility, and representative hardware/accessibility evaluation.
