# Capability matrix and release boundaries

This matrix describes the source implementation. Build results, native screenshots and release assets are tied to an exact commit; a passing earlier build does not validate later code. Browser designs use fictional data. Native operations use the real filesystem.

| Area | Implemented user workflow | Remaining boundary |
|---|---|---|
| Native workspace | Reference light/dark palette, custom SwiftUI chrome, address/history, sidebar, fitted file columns, responsive/resizable Details and Preview | Not Microsoft artwork, undocumented shell code, or a replacement for other applications' open/save dialogs |
| Dual panes | Two independent tab groups, locations, history, selection, searches and view modes; explicit active pane; editable paths; side-by-side/stacked layouts; proportional resize; narrow fallback | Auxiliary panes appear at wide widths without discarding preferences; automatic two-way folder synchronization is not implemented |
| Cross-pane operations | Copy to Other Pane and confirmed Move; destination displayed; source/destination snapshots revalidated before execution; shared collision/undo engine | A transfer is not a whole-filesystem atomic transaction |
| Tabs and windows | Multiple windows, tab reorder/cross-window transfer, duplicate/reopen/close others/right, explicit Move to New Window; durable open/closed-window sessions including companion panes | Dropping a tab on the desktop to detach is not implemented; explicit detachment is available |
| Home and navigation | Bookmark-backed Quick Access, recent documents, lazy folder tree, devices, cloud roots, tags, saved searches | No automatic usage-ranked frequent-folder engine; symlink subtrees are not expanded |
| File views | Details, list, content, tiles, four icon sizes, Gallery; custom Details headers with sort, resize, reorder, visibility, automatic sizing and persistence | No arbitrary Windows shell-extension columns; narrow user-forced column widths can require horizontal scrolling |
| Selection | Command/Control toggles, Shift ranges, separate focus/anchor, Select All/invert, checkbox mode, deterministic grid marquee with edge autoscroll, Unicode type-ahead | Keyboard behavior around collapsed groups and every provider/layout combination still needs broader interactive evaluation |
| Keyboard | Native Command and Explorer-style Control shortcuts, F-key navigation, range/focus-only movement, page movement, pane/tab switching, location/search/files focus cycling, keyboard actions sheet | Text fields and native dialogs own their keys. Physical function keys depend on the keyboard's Fn configuration; complete assistive-technology certification is not claimed |
| Touch-friendly input | 44-point file rows, headers and shared controls, modifier-free Select mode, explicit Open/actions, long-press actions, suppression of single-click-open during selection | Some system-managed and compact auxiliary controls retain native sizing. Physical touchscreen behavior depends on device/driver delivery of supported macOS input |
| Gestures | Trackpad history swipe, icon-density pinch, Gallery magnification, smart zoom/pressure Quick Look, mouse back/forward buttons, gesture preference | System gesture assignments and device hardware vary; no fabricated iPad/touchscreen compatibility layer |
| Drag and drop | Native multi-file URL and file-promise export, staged incoming promises, owning-pane source selection, folder/file-area drop, Shift-to-move, spring-loaded folder navigation | Full live cross-process interoperability is not yet verified for every source/receiver. Source files are never deleted solely because a receiver reports Move |
| Clipboard | File URL pasteboard, cut dimming, generation-scoped move reservation, exact completed-source reconciliation | External apps do not share MacExplorer's private cut intent; old operation completions cannot overwrite a newer clipboard |
| Copy/move/merge | Serialized native operation engine, coordinated staged transfers, Keep Both/Skip/Replace/Merge, independent leaf collision choices, retained replacement backups and empty merge containers | Replace and Merge are intentionally different. Completed merge children survive partial failure; cross-volume moves are not a complete crash transaction |
| Transfer progress | Native copy callback bytes, logical/clone accounting, throughput history, estimated remaining time where measurable, pause/cancel and errors | Counters are not physical disk-controller I/O. Estimates are approximate; system calls may not pause instantly |
| Undo/redo and recovery | Completed-step receipts, reversible merge/container operations, two-phase cycle-safe batch rename, recovery history and change guards | Not a complete write-ahead crash journal. Permanent deletion and metadata edits have no undo; retained recovery objects may need inspection after a process crash |
| Rename | Single/batch preview, replacement, prefix/suffix, numbering, extension preservation, two-phase swaps/cycles | Filesystem-specific normalization/case behavior still needs representative-volume evaluation |
| Trash/delete | Actual macOS Trash, restore destinations for operations tracked by this app, confirmed permanent removal | Unrelated applications' original Trash paths are not inferred. No global Empty Trash or secure-erase guarantee |
| Archives | ZIP creation; native archive header browser, navigation/filter/selection, password-aware selective/all extraction, limits, quarantine propagation and unsafe-entry rejection | No in-place archive editing or universal main-window virtual archive filesystem. Encryption depends on installed libarchive support; passwords are not stored |
| Properties | Dates, size/allocated size, owner/group/permissions, lock, tags, cloud state, SHA-256 | No privilege escalation, arbitrary ACL editor, Windows security dialog or NTFS alternate-stream tooling |
| Search | Recursive filename/metadata expressions, Spotlight content/tag/whole-Mac queries, saved expressions | Indexing and permissions affect results; recursive limits are explicit; not the complete Windows AQS language |
| Preview/Gallery | Real image/PDF raster previews, bounded caches, filmstrip, preview zoom/rotation and system Quick Look fallback | Preview rotation does not modify files. Not a Photos database client; unavailable cloud items need download |
| macOS integration | Open With, sharing/AirDrop where available, Finder tags, mounted-volume capacity/eject, Terminal, Services, login item and opt-in folder association | Finder's private desktop/Dock services are not replaced; user authorization and OS protections remain in force |
| Network/cloud | Bonjour SMB discovery, server connection routed through macOS, mounted network files, iCloud download/eviction and File Provider root discovery | Not Active Directory/workgroup or provider-specific cloud parity; no invented third-party synchronization status |
| Native validation | Core tests; actual SwiftUI PNG captures, reference palette/geometry checks, dual-pane containment and independent state, actual NSEvent/text-responder tests | Sampled screenshot checks do not prove pixel-perfect parity, complete hardware behavior or accessibility certification |
| Distribution | Universal ARM64/Intel app, ZIP/DMG, exact-commit alpha releases with native galleries/source/design/checksums; production signing/notarization/Sparkle workflows | Current alphas are ad-hoc signed and not notarized; production Apple/Sparkle credentials require owner configuration |

## Evidence and scope

The mandatory native matrix contains 68 captures on each of macOS 15 Intel and macOS 26 Apple Silicon. It includes populated Home/Details/This Mac references, dual orientations, narrow fallback, active-pane changes, touch density, file actions, keyboard help, all file modes, dialogs, transfers and archive browsing. Read the exact CI run and its logs before attributing success to a commit.

Windows COM shell extensions, NTFS-specific features, BitLocker, Windows Libraries and platform-specific cloud/network contracts are not interchangeable with public macOS APIs. Full Windows/Finder parity is not claimed. Representative hardware, providers, network shares, interrupted operations, large folders and assistive technologies remain release-evaluation work.
