## Work integrated into this build

The continuation adds cycle-safe batch rename Undo/Redo, exact completed-source reporting, reserved generation-aware cut/paste recovery, active-tab command observation, tab duplicate/reopen/reorder/cross-window transfer and detached SwiftUI windows. It integrates the existing deterministic virtualized grid selection, native multi-file dragging, spring-loaded folders, keyboard/type-ahead model, field-editor command routing and package context actions without installing duplicate drag routers.

The original archive-header build failure was removed by the system libarchive ABI bridge. The Darwin CoreGraphics overlay is explicitly imported by grid geometry and its tests. The command consumer now uses the typed `@FocusedObject` initializer, paired with `focusedSceneObject` on the workspace view.
